# 用神、喜神与忌神

用神、喜神和忌神是传统命理中用于描述五行取舍的术语。不同流派对它们的定义和取法并不完全一致，因此知识库必须记录所采用的流派或判断方法。

教学上可以先把用神理解为：针对命局主要矛盾，选择一个重点观察和调节的方向。喜神通常指对该方向有帮助的因素，忌神通常指会加重主要矛盾或削弱平衡的因素。

判断用神前，应先说明采用的是旺衰、调候、格局或其他方法。不能看到某个五行缺失，就直接把它判定为用神；也不能因为某个五行是用神，就把所有出现该五行的年份都判断为有利。

## 推荐分析步骤

1. 确认日主、月令和季节。
2. 描述命局的主要矛盾或偏向。
3. 选择明确的判断方法。
4. 给出候选用神，并说明理由。
5. 说明结论的条件、例外和不确定性。
