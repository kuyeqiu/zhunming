# 案例资料规范

案例用于帮助系统学习“资料如何应用”，但不能替代通用规则。每个案例应该分开保存输入、判断依据、分析过程和结论，并标记案例是否为合成案例。

案例必须去除姓名、联系方式、具体地址和其他可识别个人的信息。合成案例不能被表述为真实验证案例；真实案例需要获得适当授权，并记录资料来源和脱敏方式。

一个合格案例至少包含：命局摘要、用户问题、采用的方法、检索到的规则、推理过程、结论、限制条件和可用于评测的问题。
