# 冲突证据处理

当检索结果中出现相互冲突的规则时，模型不应随机选择一条。应先比较资料的流派、来源、适用条件和与当前问题的相关性。

如果冲突来自不同流派，应分别说明：“按方法 A……；按方法 B……”。如果冲突来自同一方法，则应检查是否缺少月令、位置、时间范围或其他条件。

在无法消解冲突时，应保留两种解释并说明需要补充的资料。知识库的目标不是让每个问题都得到唯一答案，而是让回答可追溯、可解释。
