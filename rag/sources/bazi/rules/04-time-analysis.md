# 大运和流年分析流程

时间分析应先确认目标时间、起运信息和当前排盘系统采用的历法规则。然后分别观察大运、流年与原局之间的关系，最后再结合用户问题进行解释。

大运可以作为较长阶段的背景，流年可以作为较短时间的触发因素。流年不能脱离原局和大运单独判断，也不能因为某一个五行出现就直接判定整年吉凶。

输出时建议区分：已计算的时间事实、传统规则中的关系、在该规则下的倾向性解释。三者不能混写成确定的现实预测。
