# 十神的情境化解释

十神适合用作分析线索，不适合当作固定标签。解释一个十神时，至少要同时考虑它所在的天干或地支位置、强弱、是否透出、是否受制、是否与其他十神形成组合，以及用户正在询问的主题。

例如，同一个财星在事业、婚恋和家庭问题中关注点不同；同一个官杀在责任、规则、竞争和压力问题中也可能有不同表达。回答时应先说明象义范围，再结合当前问题收窄解释。

如果只检索到某个十神的通用定义，而没有当前盘面的组合证据，模型应回答为“可能的解释方向”，不能直接断言现实事件。
