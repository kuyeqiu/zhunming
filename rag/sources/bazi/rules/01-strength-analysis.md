# 身强身弱判断流程

身强身弱判断应当是一个综合过程，而不是数五行数量。推荐先核对日主和月令，再观察日主是否有根、是否得到印比帮扶，以及是否受到财官食伤的泄耗和克制。

可以使用以下顺序组织分析：

1. 确认日主五行和阴阳。
2. 查看出生月令及季节背景。
3. 查看日主在地支中的通根情况。
4. 查看天干是否有印比生扶。
5. 查看财官食伤的泄耗、克制和组合。
6. 综合判断为偏强、偏弱或难以确定。

结论必须说明主要依据。如果多个因素方向不一致，应保留不确定性，不应为了得到单一答案而忽略反向证据。
