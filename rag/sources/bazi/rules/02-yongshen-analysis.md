# 用神分析流程

用神分析前，必须先说明采用的判断方法。旺衰、调候、格局等方法关注点不同，不能把不同方法的结论直接混合。

一个适合教学的流程是：先确定命局的季节和日主状态，再描述命局中比较突出的偏向或矛盾，然后提出候选五行，最后说明该候选在什么条件下可以起到帮助作用。

“缺什么补什么”不是通用规则。某个五行没有出现，只能说明它在原局中没有直接呈现，不能据此直接判定它就是用神。

检索到的资料如果只说明一般原则，模型不应把它扩展成针对当前命局的确定结论。当前命局的分析还需要结合程序生成的盘面数据。
