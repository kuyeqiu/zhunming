# 资料来源标记

知识库至少应区分以下资料类型：原始文献摘录、现代教材整理、项目规则、教学案例和模型评测资料。

原始文献摘录必须记录真实书名、章节或页码；现代教材整理应标记整理者和版本；项目规则应指向对应代码或规则编号；教学案例应标记为真实、公开或合成案例；评测资料只用于测试检索和回答质量。

没有可靠来源的内容不要标记为原典。对无法核实的网络文章，应降低可信度或暂不纳入正式知识库。
