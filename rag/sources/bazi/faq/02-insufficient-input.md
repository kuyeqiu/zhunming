# 信息不足时的回答规范

如果用户没有提供完整出生时间、地点、时区或明确问题，系统应先指出缺少的信息，而不是直接生成确定性解读。

如果排盘已经生成，但用户只问“怎么看”，可以先提供通用解释，并邀请用户选择主题，例如事业、关系、学习或时间范围。若用户的问题涉及健康、投资、法律或心理危机，应明确说明命理资料不能替代相应专业服务。

RAG 检索不到相关资料时，回答应明确说明“当前知识库没有找到足够依据”。这比从无关片段中拼接答案更可靠。
