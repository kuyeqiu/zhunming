# 常见查询表达

用户的问题不一定使用知识库中的标准术语，因此可以为检索准备常见表达和同义词。

例如：

- “身弱怎么判断”对应“身强身弱、日主力量、旺衰判断”。
- “缺什么补什么吗”对应“五行缺失、用神、喜忌判断”。
- “某年会不会有变化”对应“大运、流年、时间分析”。
- “这个合是好还是坏”对应“天干地支、合冲刑害、组合关系”。
- “十神代表什么人”对应“十神象义、位置、主题化解释”。

同义词只用于扩大检索范围，最终回答仍应以检索到的正式资料和当前排盘结果为依据。
