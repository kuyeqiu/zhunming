# 十神基础

十神是以日主为参照，对其他天干、地支中可取出的五行关系进行分类的表达方式。常见十神包括比肩、劫财、食神、伤官、正财、偏财、正官、七杀、正印和偏印。

同我者通常归入比肩或劫财；我生者通常归入食神或伤官；我克者通常归入正财或偏财；克我者通常归入正官或七杀；生我者通常归入正印或偏印。具体正偏分类还要结合阴阳属性。

十神可以作为描述人物、资源、责任、表达、竞争和关系的符号，但不能脱离日主强弱、宫位、组合和时间范围单独解释。

## 分析顺序

1. 先确定日主和五行阴阳属性。
2. 确定其他干支与日主的生克关系。
3. 标记十神名称和出现位置。
4. 结合强弱、组合和问题主题解释其作用。

## 使用限制

同一个十神在不同命局中可能有不同表现。不要把“某十神出现”直接等同于固定的人格或事件结论。
