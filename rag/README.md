# 命语 RAG 知识库练习资料

这里存放用于 RAG 练习的外部知识资料，不替代 `packages/core` 中的排盘和确定性计算逻辑。

## 当前内容

- `sources/bazi/`：八字基础教学资料
- `index/`：预留给本地向量索引或检索数据库，生成文件不建议提交到 Git
- `scripts/`：预留给资料清洗、切分和 Embedding 脚本

## 资料约定

每个 Markdown 文件包含 YAML metadata。检索时建议至少按 `method` 过滤，再根据 `topic`、`school` 和 `source_type` 进行筛选。

这些文件是教学整理版，不冒充任何古籍原文。若后续加入古籍或现代教材，应补充真实的书名、章节、页码和授权信息。

## 建议的 RAG 流程

1. 读取 `sources/` 下的 Markdown 文件。
2. 解析 metadata 和正文。
3. 按标题和段落切分成 300～800 字的片段。
4. 调用 Embedding API 并写入向量数据库。
5. 查询时先按术数类型过滤，再取最相关的 3～5 个片段。
6. 将片段和当前排盘结果一起交给大模型，并要求显示来源。
